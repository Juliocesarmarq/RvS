# Relatório comparativo – domínio e hospedagem

**Data da consulta:** 30/10/2026. Valores consultados nas páginas públicas dos fornecedores; promoções, condições e preços podem mudar. O site Raízes Verdes é estático (HTML, CSS e JavaScript), portanto não exige banco de dados nem servidor de aplicação para a publicação básica.

## 1. Comparativo

| Fornecedor / opção | Domínio `.com.br` | Hospedagem | Condições e observações |
|---|---:|---:|---|
| Registro.br + GitHub Pages | R$ 40,00/ano | R$ 0,00 | Registro.br informa R$ 40 por ano para domínio. GitHub Pages pode hospedar sites estáticos gratuitamente; domínio personalizado é contratado à parte. |
| Hostinger – plano Single | R$ 40,00/ano (registrado separadamente no Registro.br, para comparação) | R$ 5,99/mês no ciclo promocional de 48 meses | Total anunciado para 48 meses: R$ 287,52. Renovação informada: R$ 23,99/mês. O valor promocional exige contratação do ciclo de 48 meses. A página anuncia domínio grátis em planos elegíveis; conferir condições no checkout. |
| Locaweb – Hospedagem Go | R$ 40,00/ano (registrado separadamente no Registro.br, para comparação) | R$ 5,90/mês no ciclo promocional de 48 meses | Total anunciado para 48 meses: R$ 283,20. Renovação informada: R$ 20,90/mês. O plano anuncia domínio grátis no primeiro ano em extensões elegíveis; conferir condições no checkout. |

**Atenção à forma de cobrança:** os preços mensais de Hostinger e Locaweb são equivalentes promocionais de contratos de 48 meses, pagos conforme as condições do fornecedor. Não representam necessariamente uma cobrança mensal cancelável pelo mesmo valor. O domínio foi separado na tabela para permitir comparação uniforme; quando o fornecedor oferece domínio promocional, o custo e as condições do pacote devem ser conferidos antes da contratação.

## 2. Referências consultadas
- Registro.br – informações sobre domínio e preço: https://registro.br/dominio (R$ 40,00 por ano).
- Hostinger – página oficial de preços: https://www.hostinger.com/br/precos (plano Single, preço promocional e renovação).
- Locaweb – página oficial de hospedagem: https://www.locaweb.com.br/conteudos/hospedagem-de-sites-com-pagamento-mensal/ (Hospedagem Go, ciclo promocional e renovação).
- GitHub Pages – documentação oficial: https://docs.github.com/pt/pages (publicação de sites estáticos).

## 3. Comparação para o projeto
- **Custo mais baixo:** Registro.br + GitHub Pages, estimando R$ 40,00 por ano pelo domínio e hospedagem sem custo. É suficiente para publicar um site estático, desde que o repositório e as configurações estejam corretos.
- **Hospedagem paga:** Hostinger e Locaweb oferecem hospedagem tradicional, SSL e recursos adicionais. Para este projeto acadêmico, esses recursos podem ser superiores ao necessário.
- **Atenção à renovação:** comparar o preço promocional com o preço de renovação e o prazo mínimo de contratação. Não decidir apenas pelo valor mensal destacado na propaganda.

## 4. Recomendação
Para a ONG fictícia Raízes Verdes e para um site composto por HTML, CSS e JavaScript, a opção mais econômica e compatível com a necessidade técnica é **registrar o domínio no Registro.br e publicar o site pelo GitHub Pages**, sem custo de hospedagem. Essa recomendação considera apenas a necessidade de publicar um site estático; caso a ONG precise futuramente de e-mail profissional, formulários com processamento no servidor ou banco de dados, será necessário avaliar serviços adicionais.
