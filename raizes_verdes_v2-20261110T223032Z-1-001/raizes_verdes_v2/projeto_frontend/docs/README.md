# Raízes Verdes – Site da ONG Ambiental

Projeto acadêmico da disciplina **Desenvolvimento Front-End para Web**, da **UNICID**, ministrada pelo Prof. Me. Gabriel Rosa Paz.

## Objetivo

Apresentar os projetos da ONG Raízes Verdes, divulgar ações sustentáveis e permitir que interessados conheçam as iniciativas e entrem em contato.

## Integrante

- Júlio César – Desenvolvimento do projeto

## Tecnologias utilizadas

- HTML5 semântico;
- CSS3 (Grid, responsividade e Media Queries);
- JavaScript;
- Git e GitHub.
