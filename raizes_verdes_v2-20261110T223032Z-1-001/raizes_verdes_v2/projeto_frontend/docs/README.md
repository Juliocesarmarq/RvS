1. Baixe ou clone o repositório.

3. Abra `index.html` em um navegador atualizado.
4. Para editar o código, utilize um editor como Visual Studio Code.

## Formulário
O formulário de contato utiliza validações nativas do HTML5. O JavaScript apresenta uma mensagem demonstrativa após a validação, mas **não transmite os dados**: o projeto não possui servidor, API ou serviço de recebimento configurado. Para receber mensagens de verdade, o grupo deverá configurar um backend ou serviço de formulários e informar o destino autorizado.

## Endereço e contatos
Os dados exibidos na página de contato são fictícios e servem apenas para fins acadêmicos. Não utilizar como contato real.

## Validação
Antes da entrega, validar todas as páginas HTML em https://validator.w3.org/ e o CSS em https://jigsaw.w3.org/css-validator/. Registrar no diário de bordo a data, os resultados e as correções realizadas. A validação ainda precisa ser executada pelo grupo.
